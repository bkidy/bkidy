I build AI agents that do real work.

Currently at **VinkWork (Genca)**, building **[VinkClaw](https://www.vinkclaw.com)** — an enterprise office agent that connects company data and systems and gives every employee an assistant scoped by identity, permissions, and task. Web, Feishu, DingTalk, WeCom.

I care about the unglamorous loop around the model: context, memory, permissions, observability, evaluation, reliability.
